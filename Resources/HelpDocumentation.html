1

2
Import Folders: Use File → Import Folder to add individual folders to your collection.

📖Image Folder Manager - User Guide

📥1. Importing and Managing Folders

Setting Root Directory:
Go to Settings → Root Directory to set your main folder location. The application will automatically monitor this directory for changes and new folders.
Importing Individual Folders:
Click File → Import Folder to add specific folders to your collection. This is useful for folders outside your root directory.
💡 Tip: The application features real-time folder monitoring, so new folders added to your root directory will appear automatically.

🏷️2. Tag Management System

Adding Tags:
• Select a folder and use the tag input area at the bottom
• Type tags using the # symbol: #landscape #vacation
• Use categories for organization: #location:paris #mood:peaceful
Tag Categories:
Create structured tags using the format #category:tag. For example:
• #location:beach
• #season:summer
• #mood:relaxing
Batch Tag Operations:
Select multiple folders to apply tags to all of them at once. This is perfect for organizing large collections efficiently.

⭐3. Rating System

Rating Folders:
Click on the stars (1-5) to rate folders. Ratings are saved immediately and can be used for searching and filtering your best content.
Rating Tips:
• 5 stars: Your absolute best folders
• 4 stars: Excellent quality
• 3 stars: Good, worth keeping
• 2 stars: Average quality
• 1 star: Poor quality or candidates for deletion

☁️4. Tag Cloud Visualization

Accessing Tag Cloud:
Tools → Tags Cloud or press Ctrl+T
Tag Cloud Features:
• Visual overview of all your tags
• Tag size reflects usage frequency
• Category-based organization
• Left-click to search, right-click for management options

🔧5. Advanced Features

Real-time Monitoring:
The application automatically detects changes in your file system and updates the folder tree in real-time.
Image Preview:
• Supports multiple formats: JPG, PNG, BMP, GIF, WebP
• Smart caching for improved performance
• Configurable preview sizes in settings
Keyboard Shortcuts:
• Ctrl+T - Open Tag Cloud
• F1 - Open User Guide
• Ctrl+Z - Undo folder operations
• Alt+Left - Collapse parent directory

🔍Advanced Search Guide

The Image Folder Manager features a powerful search system with special syntax for precise filtering using OR groups and AND logic.

🎯Search Syntax Overview

Syntax Description Example
#tag Search by tags #landscape, #vacation
@foldername Search folder names @beach, @2023
*rating Search by rating *>=4, *=5, *<3
text General search (names & paths) vacation, photos
(term1 term2) OR group - any term matches (#nature #landscape)
group1 group2 AND logic between groups (#nature) *>3

🔗Search Logic

OR Groups:
• Use parentheses () to group terms with OR logic
• Example: (#nature #landscape) finds folders with nature OR landscape tags
• Each term in parentheses acts as an alternative match
AND Logic:
• Terms or groups separated by spaces use AND logic
• Example: #vacation *>=4 finds vacation-tagged folders AND 4+ star rating
• All conditions must be satisfied for a match

📝Search Examples

Example A: Mixed Content Search
(@man @people) #photon *>3
Logic: (Folder name contains "man" OR "people") AND tagged with "photon" AND rating > 3 stars
Matches:
• "old_man_photos" folder with #photon tag and 4-star rating ✓
• "people_gathering" folder with #photon tag and 5-star rating ✓
• "family_portraits" folder with #photon tag and 2-star rating ✗ (rating too low)
Example B: Location and Theme Search
(@sea @river) (#photon #landscape)
Logic: (Folder name contains "sea" OR "river") AND (tagged with "photon" OR "landscape")
Matches:
• "sea_sunset" folder with #landscape tag ✓
• "river_walk" folder with #photon tag ✓
• "mountain_lake" folder with #landscape tag ✗ (no sea/river in name)

🏷️Tag Search Details

Single Tag:
#landscape - Find all folders tagged with "landscape"
Multiple Tags (OR):
(#vacation #beach) - Find folders with vacation OR beach tags
Category Tags:
#location:paris - Find folders with the specific category:tag combination

📁Folder Name Search

Using @ Symbol:
@hawaii - Find folders with "hawaii" in the name
(@2023 @2024) - Find folders with "2023" OR "2024" in the name

⭐Rating Search

Rating Operators:
• *=5 - Exactly 5 stars
• *>=4 - 4 or more stars
• *<=2 - 2 or fewer stars
• *>3 - More than 3 stars
• *<4 - Less than 4 stars

🔄More Complex Examples

(#nature #landscape) *>=4 Find nature OR landscape folders with 4+ star rating (@beach @ocean @lake) #summer Find folders with beach/ocean/lake in name AND summer tag (#location:paris #location:london) (@vacation @trip) *=5 Find Paris OR London locations AND vacation/trip folders with 5 stars #family (@2023 @2024) *>2 Find family-tagged folders from 2023 OR 2024 with 3+ stars
Search Behavior:
• Searches are case-insensitive
• Parentheses create OR groups, spaces create AND logic
• Partial matches are supported
• Results update in real-time as you type
• Empty parentheses are ignored
